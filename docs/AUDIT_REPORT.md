# 1.0.0 开源发布审计报告

审计日期：2026-08-12  
审计范围：原创源码、运行时清单、数据库边界、权限、公开字段、异常、依赖、文档和发布包。  
验证基线：ZJMF-CBAP V10 10.4.6 契约、PHP 7.3 兼容目标。

## 结论

开源身份为 `CommunityGroupBuy / community_group_buy`，与其他身份的同类插件分离。仓库和发布包未发现已知的个人/公司标识、真实域名、IP、服务器路径、账号口令、私钥、令牌、客户数据或打包的 V10/官方插件源码。

本报告是维护者的代码与发布审计，不等同于独立第三方渗透测试，也不对宿主 V10 或第三方运行时组件作安全背书。

## 数据库审计

新安装 DDL 恰好创建两张插件业务表：团表与成员表。两表分别保存官方数据无法等价表达的“多人共同成团事实”和“成团前成员/权益归属”。

配置、优惠码、商品、订单、Host、插件 ID 和审计均复用官方数据。没有配置表、活动表、分享表、宣传图表、审计表或订单镜像表。

## 权限与交易审计

- 用户端路由经过 `CheckHome`、用户权限和 `ParamFilter`；写接口增加 `RejectRepeatRequest`。
- 管理端路由经过 `CheckAdmin`，查看和配置权限分离。
- 分享链接不是参团凭证，参团和领码会重新校验登录、白名单、团状态、名额、账号唯一性和补贴限制。
- 发团、参团、满员发码、权益准备、订单绑定与取消释放使用事务、行锁和唯一键。
- 权益限定本人、指定商品、数量 1、新购和首次开通；插件不修改续费价。

## 隐私与异常审计

- 用户端团列表、团详情和“我的拼团”使用独立字段白名单。
- 用户端不返回客户/订单/优惠码 ID、实际支付、支付时间、成本率、补贴参考价、预留亏损或请求幂等键。
- 成员名称打码，无可用名称时显示“匿名用户”，不回退为客户 ID。
- 可预期业务拒绝返回可执行文案；未知数据库、文件、依赖或框架异常返回稳定错误编号并写入官方审计。
- 分享地址优先使用 V10 已配置的可信会员中心 origin；文档示例统一使用 `example.com`。

## 依赖与许可证审计

原创代码使用 MIT License。V10、官方优惠码插件和宿主已有二维码组件不进入源码包或运行时包。CI 外部 Actions 固定到完整提交 SHA。

## 本地发布门

以下项目必须全部通过后才可发布：

- 所有 PHP 文件语法检查。
- 金额单元测试与业务合同测试。
- JavaScript 语法检查。
- PC/Mobile/兼容前台模板字节一致性。
- 仓库敏感信息和额外数据库表扫描。
- V10 导入包唯一根目录、20 文件清单和逐文件 SHA-256 校验。
- 源码归档排除构建目录、密钥、压缩包和环境文件。

## 已知边界

- V10 其他 10.x 小版本上线前仍需隔离站回归。
- 0.1 元模式必然产生首月亏损，必须保持默认关闭并设置白名单、预算和次数限制。
- 二维码依赖宿主已有组件；缺失时不影响核心发团数据，但邀请卡会失败。
- 卸载默认保留经营和订单归因数据；彻底删除由站点运营方另行决策。
